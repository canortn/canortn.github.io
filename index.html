Scratch Tic-Tac-Toe — Documentation

This Scratch project is a Tic-Tac-Toe game I built with help from my friend Ömer Eren Hatipoğlu. Nine tiles toggle between X and O; win sprites check rows, columns, and diagonals, highlight the winning line, and stop input. Next steps: fix edge-case bugs, add win/draw counters, a reset and scoreboard, player vs. CPU mode, sound effects, and cleaner code.
