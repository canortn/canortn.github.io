Big Idea 1 — Creative Development

In this unit I practiced turning an idea into a working program by planning, iterating, and clearly communicating my design. I kept short notes and screenshots as documentation and created a quick narration to explain how the program works and why I built it.

  • 1.1 Collaboration: We used teamwork to split tasks and problem-solving to unblock each other during bugs.
  • 1.2 Program Design & Development: I wrote simple algorithms, drafted pseudocode, and used debugging (print checks, step-by-step tests) to refine behavior.
  • 1.3 Program Function & Purpose: Defined the goal and audience, mapped input/output, grouped logic into functions/procedures, and recorded documentation so others can understand and reuse it.
  • 1.4 Identifying & Correcting Errors: Wrote small tests, tried edge cases, and added basic error handling to avoid crashes or invalid inputs.

4-minute narration: a short screen-recording that summarizes the purpose, key features, and one example of debugging. (See the video below.)

Scratch Tic-Tac-Toe — Documentation

This Scratch project is a Tic-Tac-Toe game I built with help from my friend Ömer Eren Hatipoğlu. Nine tiles toggle between X and O; win sprites check rows, columns, and diagonals, highlight the winning line, and stop input. Next steps: fix edge-case bugs, add win/draw counters, a reset and scoreboard, player vs. CPU mode, sound effects, and cleaner code.
